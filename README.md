# citrust-bloom-comfort-firefox-theme

A soft lavender and warm ivory Firefox theme designed to create a calm, comfortable, and visually balanced browsing experience.

## Preview

![Citrus Bloom Firefox Theme](citrus-header.jpg)

## Overview

**Citrus Bloom — Comfort Edition** is a minimalist Firefox static theme combining a botanical-inspired header with a muted lavender, warm ivory, and soft plum colour palette.

The theme is designed to provide a gentle visual contrast while maintaining readability and a cohesive browser interface.

## Colour Palette

| Colour | Hex Code | Application |
|---|---|---|
| Deep Plum | `#594A70` | Browser frame and icons |
| Muted Lavender | `#E8DFF0` | Toolbar |
| Warm Ivory | `#FFF9F0` | Selected tabs and input fields |
| Soft Lilac | `#D3C6DF` | Borders and separators |
| Charcoal | `#34313C` | Interface typography |
| Muted Terracotta | `#C87555` | Attention indicators |

## Installation

### Temporary Installation (Developer Mode)

1. Download and extract the ZIP archive.
2. Open Firefox and navigate to `about:debugging`.
3. Select **This Firefox**.
4. Click **Load Temporary Add-on…**.
5. Select the `manifest.json` file.

The theme will be loaded for testing. Temporary add-ons are removed when Firefox restarts.

### Permanent Installation

For permanent installation and public distribution, the package must be submitted to [Mozilla Add-ons (AMO)](https://addons.mozilla.org/) for signing.
